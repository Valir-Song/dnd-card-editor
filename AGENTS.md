# Работа в репозитории

Перед изменениями прочитай [CLAUDE.md](CLAUDE.md): это общая памятка проекта для Codex и Claude,
с устройством кода, правилами сохранности данных, командами и проверками.
Актуальные возможности и формат описаны в [README.md](README.md), приоритеты и решения владельца —
в [docs/ROADMAP.md](docs/ROADMAP.md). Не создавай отдельный план для другого помощника.

Сохраняй чужие изменения. Используй существующий checkout облачной задачи; worktree — только по просьбе владельца.
Отвечай по-русски. Не начинай отложенные задачи и не вливай будущие изменения без разрешения в рамках их задачи.
