# D&D Card Editor

Офлайн-редактор листов-шпаргалок A4 для персонажа D&D 5e (начинался с листа барда Ричарда Сэдсонга):
карточки заклинаний и способностей, заметки, ресурсы, фигуры, картинки и
свободные текстовые поля на двух страницах. Весь редактор — один HTML-файл:
без сервера, без установки и без интернета.

Текущая версия: **3.11.0 beta** (ветка `main`). Стабильная 3.2.0 без Moveable/Selecto —
коммит `d2493ae` в истории `main`; версия 3.1 до Tiptap — ветка `archive/stable-3.1-before-tiptap`.

## Как пользоваться
1. Открой `DND_Card_Editor_standalone.html` в Chrome или Firefox.
2. Редактируй: клик по объекту — выделить, клик по тексту — печатать.
3. Впиши имя макета в **Файл → Название** (например, имя персонажа).
4. Храни работу кнопкой **Файл → Скачать HTML**. Получится новый файл-редактор с твоим макетом
   и картинками внутри — **это главная, надёжная копия**. Дальше открывай уже его.

### Приложение: значок на рабочем столе, без скачивания новых версий
- Открой **https://valir-song.github.io/dnd-editor/** в Chrome или Edge и нажми значок «Установить» справа в
  адресной строке (или меню ⋮ → «Установить приложение»). Появится значок-кубик на рабочем столе и в «Пуске»,
  редактор откроется в своём окне.
- **Всегда последняя версия:** при запуске с интернетом приложение берёт свежую версию само (из `main`).
  Без интернета открывается версия, загруженная в прошлый раз.
- **Бета** для проверки новых функций — **https://valir-song.github.io/dnd-editor/beta/**, ставится отдельным
  значком с буквой β. У беты **свои сохранения**: пробная версия не трогает макеты основного приложения.
- Сохранения приложения хранятся отдельно от сохранений HTML-файлов на диске (у браузера это разные «места»).
  Чтобы перенести макет: в старом файле **Файл → Скачать JSON**, в приложении **Файл → Импорт JSON**.
- Сам макет в интернет не уходит: он хранится в браузере и в файлах, которые ты сохраняешь.

### Новый лист и готовые листы
- Кто открывает редактор впервые, видит **пустой шаблон**: два листа с надписями «Имя персонажа»,
  «Название заклинания» и т. п. Их заменяют своими; лист сам сохраняется в браузере.
- **Файл → Новый лист…** — начать новый лист: с пустого шаблона или с копии **готового листа**
  (первый — «Бард — Ричард Сэдсонг»). Прежний лист остаётся в «Мои макеты», оригинал готового листа не меняется.
- Готовые листы лежат на сайте рядом с приложением и скачиваются, только когда их выбрали: файл редактора от этого
  не растёт. Приложение запоминает скачанный список и листы для работы без интернета; HTML-файлу с диска для списка
  нужен интернет.
- **Пополнить базу** (пока вручную, владелец): сохранить лист в файл `.dnd` (Ctrl+S в приложении), затем на GitHub
  в репозитории `dnd-card-editor` открыть папку `library` → **Add file → Upload files** → перетащить файл →
  **Commit changes**. После зелёной проверки CI лист сам появится в списке. Название в списке — название макета,
  строка под ним — подзаголовок шапки листа. Подробнее — `library/README.md`.

### Макет — отдельный файл, как документ Word
- **Ctrl+S** в приложении сохраняет макет в файл `Имя.dnd` (первый раз спросит, куда), дальше пишет в тот же файл.
  В HTML-файле с диска Ctrl+S по-прежнему пишет HTML; в окне сохранения можно выбрать и другой тип.
- **Файл → Открыть…** (Ctrl+O): макет `.dnd`, скачанный HTML редактора **любой версии** или JSON. Открытый файл
  становится файлом макета — Ctrl+S сохраняет обратно в него. Внизу окна — **недавние файлы**.
  Так старые HTML-копии разбираются по одной: открыть, Ctrl+S в `.dnd`, старый файл можно удалить.
- В установленном приложении `.dnd` открывается **двойным щелчком** (Windows один раз спросит, чем открывать).
  У файлов `.dnd` свой значок — листок с кубиком d20 (если остался обычный значок, переустанови приложение).
- Если в браузере есть более поздняя версия того же макета, откроется она, а под панелью будет кнопка
  «Открыть как в файле». Более ранняя версия из браузера сохраняется копией в «Мои макеты».
- В Firefox файл открывается копией, а сохранение — скачиванием.

### Сохранить в файл (Ctrl+S) и ярлык
- **Ctrl+S** или кнопка **💾 В файл** (рядом с «Отменить») в Chrome и Edge: первый раз браузер спросит, куда
  сохранить (можно выбрать тот же файл, который открыт), дальше Ctrl+S молча сохраняет в него —
  как в обычной программе. Имя файла видно рядом со значком «✓ Сохранено». **В другой…**
  (Ctrl+Shift+S) — выбрать другой файл. После перезапуска браузер один раз спросит разрешение.
- В Firefox и других браузерах Ctrl+S скачивает копию в «Загрузки», как «Скачать HTML».
- **Ярлык:** положи файл в постоянную папку (не «Загрузки»), открой его в Chrome двойным щелчком, затем
  меню ⋮ → «Трансляция, сохранение и отправка» → «Создать ярлык…» → «Открыть в отдельном окне».
  У вкладки и ярлыка своя иконка — кубик d20.

### Автосохранение в браузере
Пока ты работаешь, редактор сам сохраняет макет в браузер. Это удобство, а не замена скачанному файлу:
браузер может очистить свои данные.

- **Значок рядом с «Отменить»** показывает состояние: «✓ Сохранено», «Сохраняю…» или «⚠ Не сохранено».
- **Закрыть вкладку**, пока изменения не записаны, браузер даст только после вопроса.
- **Если сохранить не удалось**, под панелью появится предупреждение с кнопками «Скачать HTML / JSON».
- **Места хватает надолго:** макет хранится в базе браузера (IndexedDB) — сотни мегабайт вместо прежних ~5 МБ.

### Несколько макетов
- **У каждого макета своё сохранение.** Файлы разных персонажей не мешают друг другу.
- **Файл → Мои макеты** — все макеты этого браузера с датой и размером: открыть, скачать JSON, удалить.
- **Новая версия редактора** (чистый файл без макета) открывает твой последний макет — после обновления
  ничего не теряется.

### Если открылось не то
- Если версия в браузере новее файла (или наоборот), открывается **более свежая**, а под панелью —
  кнопка открыть другую. Ни одна не теряется.
- **Файл → Сбросить сохранение браузера** открывает макет, записанный в самом файле. Перед этим
  скачивается резервная копия JSON, а Ctrl+Z возвращает прежний макет.
- Файлы из старых версий (3.3–3.8) тоже находят своё сохранение; если в браузере есть более поздняя
  работа, под панелью появится кнопка её открыть. Сохранение из версий до 3.8 переносится само.

## Возможности
- **Панель-лента, как в Word:** вкладки (Карточки, Оформление, Текст, Фигуры, Кружочки, Слои, Выравнивание,
  Файл) — в тёмной верхней строке рядом с «Отменить» и сохранением; под ними кнопки с иконками в подписанных
  группах. Высота панели всегда одна, поэтому лист не прыгает при выделении и смене вкладки.
- **Карточки:** добавить, дублировать, удалить. Название, мета-строка, описание и значок
  уровня (♪ — предмет).
- **Привязка и сетка:** при перетаскивании и изменении размера края и центры объектов прилипают
  к краям и центрам других объектов той же страницы, к рамке листа (5 мм) и к его центру;
  в момент привязки видна розовая направляющая. Переключатель «Привязка» и выбор сетки
  (1 / 2,5 / 5 мм) — в верхней панели, настройка запоминается в браузере. Alt во время
  перетаскивания временно отключает привязку. Порог — 6 пикселей экрана. **Равные промежутки:** карточка
  рядом с рядом (или столбцом) прилипает к такому же промежутку, как между соседями, или встаёт ровно
  посередине между двумя; розовые отметки показывают равные промежутки и их размер в мм. Учитываются только
  объекты того же ряда или столбца; к краю или промежутку — что ближе. Включённая сетка видна на
  листе бледными линиями (каждый сантиметр чуть темнее; при сетке 1 мм — линии через 5 мм); только на экране,
  не на печати и не в скачанном файле.
- **Стрелки:** сдвигают выделенное на 1 мм, Shift+стрелки — до следующей линии сетки (без сетки — на 5 мм);
  группа не выходит за лист, закреплённые стоят, серия нажатий — один шаг отмены. Когда курсор в тексте, стрелки
  двигают курсор; Esc выходит из текста, и тогда стрелки двигают рамку этого текста внутри карточки.
- **Текстовые рамки внутри карточки** (тот же слой жестов): клик по тексту выделяет его рамку;
  тяни за контур — сдвинуть, за ручки — изменить размер. Shift+клик или Alt+рамка по пустому
  месту карточки выделяют несколько её текстов; клик по пустому месту карточки возвращает к ней.
  Смещения хранятся в `textFrames` относительно карточки и сохраняются при её перемещении.
  Текст прилипает только к своей карточке: к её краям, полю внутри отступов, центру и другим её текстам
  (направляющая — в пределах карточки); к соседним объектам и к сетке листа — нет.
  Удаление при выделенном тексте карточку не удаляет. Значок уровня сдвигается отдельно.
- **Холст (собственный слой жестов, мышь, палец и стилус):** перетаскивание и изменение размера за 8 ручек;
  тянуть можно и за полосу сразу за краем рамки — удобно для карточек, сплошь занятых текстом;
  Shift на угловой ручке сохраняет пропорции; Shift+рамка добавляет к выделению;
  выделение нескольких объектов рамкой по пустому листу или Shift+клик (в пределах
  одной страницы); группа двигается и масштабируется как одно действие; удаление группы.
- **Текст (Tiptap):** единая панель для всех полей — Ж/К/Ч/S, шрифт, размер 6–96 pt,
  цвет, выравнивание, списки, очистка оформления. Курсор без выделения применяет
  стиль ко всему полю. Текстовое поле: заливка, рамка, высота по тексту.
- **Темы** (вкладка «Оформление»): готовое оформление карточек и блоков — фон, рамка, цвета заголовка,
  мета-строки и кружочка: «Пергамент», «Лес», «Ночь», «Пламя», «Лёд», «Море», «Золото», «Камень», «Кровь»,
  «Тень». Действует на выделенное, а если ничего
  не выделено — на весь лист; «Тему на весь лист» — всем сразу. Шапка и заголовки секций меняют только цвет
  текста. Фигуры, картинки и текстовые поля не меняются. Ctrl+Z отменяет одним шагом.
- **Рамки** (вкладка «Оформление»): сплошная, двойная, пунктир, точки, с внутренней линией, уголки; толщина
  и цвет (без своего цвета — цвет темы). Для карточек, блоков, картинок и фигур; выделенному или всему листу.
  Рамка рисуется поверх края, текст внутри не сдвигается.
- **Фон листа** (вкладка «Оформление»): 8 готовых фонов (белая и старая бумага, камень, дерево, лес, море,
  пламя, звёздная ночь) или своя картинка (заполнение, прозрачность); на текущий лист или на оба. Фон не
  выделяется и не мешает выделять объекты.
- **Оформление:** цвет фона; фон-картинка карточки (заполнение, прозрачность, масштаб,
  сдвиг, затемнение); для картинок — прозрачность, яркость, контраст, поворот.
- **Фигуры и изображения:** прямоугольник, круг, линия; картинка из файла или Ctrl+V.
- **Новые объекты не налезают на старые:** появляются под выделенным объектом или посередине видимой
  части листа, в ближайшем свободном месте; копия карточки — прямо под оригиналом.
- **Сжатие картинок:** картинки и фоны карточек при загрузке уменьшаются до 1600 точек по длинной
  стороне (JPEG, прозрачные — WebP/PNG): фото с телефона в 3–5 МБ становится несколькими сотнями КБ,
  на печати разницы не видно. Кнопка **Файл → Сжать картинки** уменьшает уже загруженные (Ctrl+Z вернёт).
- **Кружочки** (своя вкладка): на карточке, заметке и «Ресурсах». «+ Кружок» — сначала главный (бывший
  значок уровня), затем ещё рядом; «− Кружок» — убрать; 7 цветов и 31 знак (★ ✦ ☀ ☾ ♪ ⚔ ✚ ☠ ⚡ ❄ ♥ …, а также
  буквы К и Р) вместо цифр. Знак и цвет — кружочку, по которому щёлкнули последним, иначе главным кружочкам всех
  выделенных карточек. Щелчок по кружочку — печатать в нём, перетаскивание — сдвинуть.
- **Слои:** на передний/задний план, выше/ниже (в пределах страницы).
- **Выравнивание** (своя вкладка): по левому/правому краю, по верху/низу, по центру и середине выделения;
  «Распределить ↔/↕» — равные промежутки (от трёх объектов, крайние стоят); «Одна ширина/высота» — как у
  первого выделенного (Shift+клик — с какого начали, рамкой — верхний левый). Один объект выравнивается по рамке
  листа (5 мм) или по его центру. Закреплённый объект — опора: остальные встают по нему, сам он не двигается.
  Выделенные тексты карточки выравниваются между собой, один текст — внутри карточки. Каждая кнопка — один шаг
  отмены.
- **Закрепить** (вкладка «Карточки», Ctrl+Shift+L): закреплённый объект — например, фон или рамку секции —
  нельзя сдвинуть, растянуть или удалить; рамка-выделение проходит мимо него и может начинаться прямо на нём,
  поэтому карточки поверх фона выделяются как на пустом листе. Щелчок его выделяет (у рамки — замок),
  текст и цвет меняются как обычно. Копии и дубли появляются незакреплёнными. «🔓 Открепить всё на странице» снимает все замки текущей
  страницы одним шагом отмены.
- **Действия с группой** (несколько объектов, выделенных рамкой или Shift+клик): дублировать
  (копии сохраняют взаимное расположение и встают под группой), слои (порядок внутри группы
  сохраняется), цвет фона, удаление — всё одним шагом отмены.
- **Копировать / вырезать / вставить объекты:** Ctrl+C, Ctrl+X, Ctrl+V для выделенных объектов (не текста).
  Копия встаёт под оригиналом, вырезанное — на своё место; вставлять можно и в другой файл
  (другого персонажа). Когда курсор в тексте, эти клавиши работают с текстом, как обычно.
- **Файл:** сохранить в браузере, скачать HTML, экспорт и импорт JSON, печать/PDF (A4, без
  панелей и рамок выделения).
- **История:** Ctrl+Z / Ctrl+Y / Ctrl+Shift+Z (работает и в русской раскладке), до 60 шагов,
  до перезагрузки страницы. Картинки в истории хранятся по одному разу, поэтому крупные фото не
  сокращают число шагов. Одно перетаскивание или серия нажатий — один шаг.

### Защита данных
- Импорт JSON сначала проверяется (тип объекта, страница 1–2, числовые координаты) и
  отрисовывается; при ошибке текущий макет и сохранение в браузере не меняются, а
  сообщение называет проблемный объект.
- Если сохранённый в браузере макет повреждён, редактор открывает встроенный шаблон и
  предлагает скачать копию повреждённых данных (копия также лежит в localStorage
  `dnd-card-editor-v3-recovery`, если помещается).
- «Сохранить» дожидается записи и честно сообщает, если сохранить в браузер не удалось.
- Выбор между макетом в файле и в браузере — по времени (3.3.2). Вытесненный макет из браузера
  хранится отдельной записью `<номер макета>:previous` (видна в «Мои макеты»).

## Разработка
Нужен Node.js 22 LTS (с npm) и, для браузерных тестов, Python 3.12.

```sh
npm ci                     # зависимости строго по package-lock.json
npm run dev                # http://127.0.0.1:5173
npm test                   # Node-тесты: история, проверка макета, исходники
npm run typecheck          # TypeScript проверяет JS-код: опечатки в именах, полях объектов, аргументах;
                           # весь код — в строгом режиме (strict)
npm run build              # dist/index.html — один офлайн-файл
npm run check:build        # проверка, что сборка самодостаточна
npm run standalone         # сборка + обновление DND_Card_Editor_standalone.html
npm run site               # приложение для сайта в site/ (и бета в site/beta/): манифест, иконки, офлайн-кэш

pip install -r tests/requirements.txt
python -m playwright install chromium firefox
npm run test:e2e           # все браузерные тесты в Chromium (Windows тоже)
npm run test:e2e:firefox   # то же в Firefox
CPU_THROTTLE=4 npm run test:e2e   # Chromium с 4-кратно замедленным процессором (ловит гонки)
python tests/visual_browser_smoke.py   # снимки страниц против редактора из main (нужен npm run build)
```

В облачных сессиях Claude Code скрипт `.claude/hooks/session-start.sh` при старте сам ставит зависимости
и прогоняет Node-тесты и проверку типов (на своём компьютере он ничего не делает).

**Сайт-приложение.** `scripts/build-site.mjs` добавляет к той же сборке манифест, иконки (`app/`) и
service worker (`app/sw.js`), помечая всё добавленное `data-app-only` — «Скачать HTML» это вырезает. Публичный
репозиторий `Valir-Song/dnd-editor` (GitHub Pages) хранит только готовые файлы: корень — версия из `main`,
`beta/` — проверяемая ветка. Выкладывает `.github/workflows/publish.yml`: после зелёного CI на `main` — основную,
запуском вручную (Actions → Publish app → ветка, beta) — бету. Ему нужен секрет `PAGES_TOKEN` (fine-grained token
с правом Contents: read and write только на `dnd-editor`); без него задание ничего не делает.

После изменения версии в `package.json` и `index.html` выполни `npm run standalone`:
`npm test` проверяет, что закоммиченный standalone-файл соответствует текущей версии.

GitHub Actions на каждый PR запускает Node-тесты, проверку типов, сборку, сверку standalone-файла со сборкой и все
браузерные наборы в Chromium и Firefox, а затем ещё раз в Chromium с 4-кратно замедленным процессором.
Хвост упавшего набора виден аннотацией прямо в PR; собранный HTML доступен как артефакт запуска.

### Формат макета
Скачанный JSON (с 3.11.0 beta.13) — `{"format": "dnd-card-editor/layout", "formatVersion": 2, "name", "editor", "savedAt", "items": [...]}`:
номер версии формата, название макета, версия редактора, время и сами объекты. Голый JSON-массив объектов из прежних
версий — это формат 1, он по-прежнему открывается и при открытии обновляется до текущего (`MIGRATIONS` в `src/editor/layout.js`).
Файл с более новым форматом, чем знает редактор, не открывается (с понятным сообщением), а такое сохранение браузера
не перезаписывается. Номер формата есть и в сохранении браузера, и в скачанном HTML (`#initial[data-format-version]`),
и в буфере обмена.
Файл макета `.dnd` (с 3.11.0 beta.15) — тот же JSON, что «Скачать JSON», плюс `"id"` — номер макета, по которому
файл находит своё сохранение в браузере.

Каждый объект — общие поля: `id`, `kind` (`header`, `note`, `resources`, `section`,
`card`, `shape`, `image`, `textbox`, `sheet`), `page` (1–2), `x`, `y`, `w`, `h` в миллиметрах, `z`.
Текст хранится в `title/subtitle/meta/detail/text` и оформленный — в `…Html`; смещения
текстовых рамок карточки — в `textFrames[поле] = {x, y, w, h}`; `badgeColor` — цвет главного кружочка, `badges: [{text, x, y, color}]` — дополнительные кружочки; `theme` — тема оформления (`parchment`, `forest`, `night`, `ember`, `ice`, `sea`, `gold`, `stone`, `blood`, `shadow`); `outline` — рамка (`solid`, `double`, `dashed`, `dotted`, `ornate`, `corners`), `outlineColor` — её цвет, `outlineWidth` — толщина в мм; `locked: true` — объект закреплён
(поле необязательное, нет поля — не закреплён).
Фон листа — объект `kind: "sheet"` (не больше одного на страницу, геометрия — весь лист): `sheet` — готовый фон
(`paper`, `oldpaper`, `stone`, `wood`, `forest`, `sea`, `ember`, `night`; нет поля — пергамент),
`src` — своя картинка (`data:` URL), `fit` (`cover`/`contain`/`fill`) и `opacity` (0–100). Нет объекта — обычный лист. Старый `<font>` из версий до
3.2 при загрузке превращается в стили Tiptap.

## История версий
- **3.11.0 beta.17** — новый человек видит не лист Ричарда, а пустой шаблон («Имя персонажа», «Название заклинания»…);
  «Файл → Новый лист…» начинает новый лист с шаблона или с копии готового листа, прежний остаётся в «Мои макеты».
  Готовые листы — файлы `.dnd` в папке `library/` (первый — «Бард — Ричард Сэдсонг»): они лежат на сайте рядом
  с редактором и скачиваются, только когда их выбрали, поэтому файл редактора не растёт. Название макета следует
  за именем в шапке, пока его не меняли вручную.
