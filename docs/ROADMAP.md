## Принципы
1. **Один HTML-файл, без интернета и установки.** Любая функция работает в скачанном файле офлайн в Chrome и Firefox.
   Никаких серверов, аккаунтов и внешних шрифтов/скриптов. Приложение с сайта — дополнение, а не замена файла.
2. **Работа владельца не теряется.** Старые макеты (с 3.2) открываются; новое поле — необязательное, новый смысл
   поля — шаг в `MIGRATIONS`; при ошибке — понятное сообщение и путь назад (Ctrl+Z, копия).
3. **Перед игрой надёжность важнее новизны.** Крупные переделки — не накануне сессии D&D.
4. **Каждая функция — с тестом**, который падает без неё; CI в Chromium и Firefox зелёный.
5. **Маленькие PR.** Один шаг — один PR. Вливание — только по слову владельца.

## Как читать размер (S / M / L / XL)
Это **примерный объём работы**, а не срок: S — небольшая правка в одном-двух местах; M — новая функция на несколько
модулей с новым разделом теста; L — затрагивает многое (геометрию, формат, все жесты); XL — серия PR.
Написать код, пройти автоматические проверки (CI ~4–6 мин на прогон, но падение — новый круг) и ручную проверку
владельцем — три разных отрезка времени, и последний зависит от того, когда владелец сможет попробовать. Сроков не обещаем.

## Открытые и частично сделанные пункты

### 1.7 Надёжность CI — S (открыт)
- **Зачем:** на `main` иногда появляется красный крестик, хотя редактор в порядке, — владелец пугается.
- **Осталось:** при пачке вливаний подряд CI ранних коммитов падает на шаге «Fetch main for the visual reference»
  (`main` ушёл вперёд, fetch не fast-forward) — добавить `+` в refspec в `verify.yml` (проверено 26.10.2026: `+` ещё нет).
- **Уже сделано:** раздел 18 `regression` ждёт курсор и выделение редактора (da009ea, #54); повтор не замечен,
  но и не подтверждён. Закрепление `ubuntu-24.04` — в PR #64 (см. «Известные проблемы»).

### 2.2 Напоминание сохранить копию — S (открыт, ждёт решения владельца — вопрос 1)
- **Зачем:** браузер может очистить своё сохранение (очистка истории, инкогнито, переполнение), надёжна только копия
  вне браузера.
- **Что (исходный план):** ненавязчивая плашка «изменения не скачаны уже N минут / с прошлой игры»; время последнего
  скачивания хранить рядом с сохранением. Что считать копией после появления `.dnd` и Ctrl+S — решает владелец.

### 2.4 Отмена переживает перезагрузку — M (открыт)
- **Зачем:** сейчас история Ctrl+Z пропадает при закрытии вкладки.
- **Что:** сохранять последние шаги истории (с пулом картинок) в IndexedDB; ограничить объём. IndexedDB (1.5) уже есть.

### 3.8 Поиск по макету — S (открыт)

- **Что:** поле поиска; подсветка и выделение найденных карточек, переход к ним. Сейчас поиск есть только

## История: сделанные пункты
Номера прежние. У каждого — зачем, что сделано, решения и совместимость. Версии и PR без пункта плана — в таблице ниже.

### 1.1 Строгая проверка типов — S/M (3.8 beta.2 #19, 3.11.0 beta.6 #36, beta.13 #45)
- **Зачем:** TypeScript ловит опечатки, но без строгого режима пропускает забытые аргументы, `undefined` вместо числа,
  неверные возвраты — чем строже, тем раньше видна ошибка.
- **Сделано по шагам:** `tsconfig.strict.json` для 7 чистых модулей (#19, типы геометрии — `src/types/geometry.d.ts`) →
  ещё `notice`, `toolbar-tabs`, `dom`, `interactions`, всего 20 (#36; нашёлся значок удалённой карточки) → последние девять
  (#45). Теперь `strict` в самом `tsconfig.json`, отдельный конфиг убран; Node-тест не даёт выключить строгость или
  обойти её (`@ts-ignore`, `any`). Помощники `editor.js` описаны интерфейсом `Editor`, модуль берёт нужные через
  `Deps<'current' | …>`. Настоящих ошибок не нашлось; закрыты места, которые упали бы на странном входе.

### 1.2 Номер версии формата макета — S (3.11.0 beta.13, #45)
- **Зачем:** безопасно «переселять» старые макеты при новых полях и понимать, из какой версии пришёл файл.
- **Сделано:** JSON — `{format, formatVersion, name, editor, savedAt, items}`; номер есть и в записи браузера, и в скачанном
  HTML (`data-format-version`), и в буфере обмена. Голый массив = формат 1. `MIGRATIONS` в `layout.js`: 1→2 — перенос
  значка 3.4 (раньше в `startup.js`); 2→3 — ресурсы «□» в строки (3.11.0 beta.18, #51). **Сейчас формат 3.**
