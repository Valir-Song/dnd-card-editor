Ричард · редактор 3.3 · Moveable + SelectoCtrl+Z: отмена · Ctrl+Y: повтор · Shift+клик: несколько · рамка по пустому листу: выделить · текст: редактировать · ⠿: передвинуть текст · Ctrl+V: картинка
Редактирование: Для фонового рисунка выдели карточку и выбери «Фон карточки → Изображение». Изменяй прозрачность, масштаб, положение, затемнение и режим заполнения. выбери карточку и поменяй её фон в верхней панели. Клик по тексту — редактирование; у выделенного объекта перетаскивай значок ⠿ возле текста, а нижний уголок — для изменения его рамки; выдели слова и используй общую панель Tiptap для форматирования. Картинку можно вставить Ctrl+V из буфера либо через «+ Картинка». Moveable: рамка выделения, перетаскивание и масштабирование объектов; Selecto: выделение рамкой по пустому листу, Shift+клик — добавить объект. Выдели картинку, чтобы изменить прозрачность, яркость, контраст, поворот и заполнение. Кнопки слоёв меняют порядок наложения всех объектов. Отменить: Ctrl+Z, повторить: Ctrl+Y или Ctrl+Shift+Z. История действий хранится до закрытия страницы. Нажми «Скачать HTML», чтобы сохранить весь макет, включая изображения.
