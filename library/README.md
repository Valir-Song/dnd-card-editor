# Готовые листы

Каждый файл `.dnd` в этой папке — один готовый лист в окне редактора **Файл → Новый лист… → Готовые листы**.
Листы публикуются на сайт рядом с редактором (`scripts/build-site.mjs`) и скачиваются, только когда игрок их
выбрал, поэтому сколько бы их ни было, файл редактора не растёт.

## Как добавить лист
1. В редакторе впиши **Файл → Название** так, как лист должен называться в списке, например «Бард — Ричард Сэдсонг».
2. Сохрани его в файл `.dnd` (Ctrl+S в приложении).
3. На GitHub открой эту папку → **Add file → Upload files** → перетащи файл → **Commit changes**.
4. Проверка CI убедится, что файл открывается (иначе — красный крестик и понятная ошибка в тесте `library`).
   После вливания в `main` лист появится на сайте.

Строка под названием в списке — подзаголовок шапки листа («Бард 6 · Коллегия очарования …»).
Убрать лист — удалить его файл. Имя файла лучше латиницей и без пробелов (`richard-sadsong.dnd`), но это не обязательно.
