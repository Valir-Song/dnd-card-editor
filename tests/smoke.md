# Ручная проверка перед релизом

Автотесты (`npm test`, `npm run test:e2e`, `npm run test:e2e:firefox`) проверяют многое,
но не заменяют прогон с настоящим макетом. Перед проверкой скачай JSON текущего макета.

- [ ] `DND_Card_Editor_standalone.html` открывается без интернета в Firefox и Chrome
- [ ] Отображаются все объекты макета на обеих страницах
- [ ] «Справка» справа вверху (и F1) открывает окно с разделами; Esc, ✕ и щелчок мимо окна его закрывают; текст в разделах правдив
- [ ] «Персонаж» справа вверху: ХАР 16 и уровень 6 → модификатор +3, бонус +3, «Выступление» с экспертизой +9; вписанное вручную число жёлтое, ↺ возвращает подсчёт; на листе и в печати ничего нового; после перезапуска числа на месте; в режиме игры окно только для просмотра
- [ ] «Карточки → Характеристики, Навыки, Бой»: окошки показывают числа «Персонажа», меняются вслед за окном; «Все навыки» показывает 18; двойной щелчок открывает окно; на печати окошки видны и читаются
- [ ] Выделение кликом, Shift+кликом и рамкой по пустому листу; счётчик «Выбрано: N»
- [ ] Перемещение и изменение размера одного объекта и группы; отмена — одним шагом
- [ ] Клик по тексту карточки: рамка текста двигается за контур и меняет размер за ручки, карточка стоит на месте
- [ ] Shift+клик и Alt+рамка выделяют несколько текстов одной карточки; клик по пустому месту карточки возвращает к ней
- [ ] Значок уровня сдвигается отдельно
- [ ] **Firefox:** выделить карточку, зажать Shift и обвести рамкой другую — выделены обе (автотест в Firefox
      ведёт этот жест синтетическими событиями: Playwright не доставляет его настоящей мышью)
- [ ] Привязка: карточка прилипает к краю соседней, видна розовая линия; Alt и выключатель её отменяют; сетка 5 мм работает
- [ ] Редактирование и форматирование текста во всех типах полей
- [ ] Изменение → значок «✓ Сохранено»; закрыть и открыть файл снова (в Chrome и в Firefox) — изменение на месте
- [ ] Два скачанных файла с разными названиями: правки в одном не появляются в другом; «Файл → Мои макеты» показывает оба
- [ ] Закрытие вкладки сразу после правки большого макета: браузер спрашивает «покинуть страницу?» только пока идёт запись
- [ ] Ctrl+C / Ctrl+V объекта и группы: копия под оригиналом; Ctrl+X и Ctrl+V — на прежнее место;
      вставка в **другой** файл (в Chrome и **в Firefox** — там это проверяется только вручную); в тексте Ctrl+C/V копирует текст
- [ ] Группа (рамкой или Shift+клик): «Дублировать», слои, цвет фона действуют на все; Ctrl+Z — одним шагом
- [ ] Стрелки двигают карточку на 1 мм, Shift+стрелки — по сетке; удержание стрелки — плавный сдвиг, Ctrl+Z
      отменяет всю серию; в тексте стрелки двигают курсор; Esc после щелчка по тексту — стрелки двигают его рамку
- [ ] Сетка 5 мм видна бледными линиями и не мешает читать; на печати и в «Печать / PDF» её нет
- [ ] Перетащить карточку к ряду карточек: прилипает к тому же промежутку, видны розовые «10» и т.п.; не
      «залипает» навязчиво (порог маленький), Alt во время перетаскивания отключает; текст внутри карточки
      прилипает к её полю и к другим её текстам, но не к соседним карточкам
- [ ] Кружочки: «+ Кружок» на карточке без кружочка и ещё два; знаки ★ ⚡ ☾ видны как значки, а не цветные эмодзи
      (Chrome и Firefox); цвет; щелчок по кружочку и печать цифры; перетаскивание; печать на бумаге
- [ ] Темы: каждая из десяти на весь лист — читается ли текст, как выглядит на печати (особенно «Ночь» и «Тень»)
- [ ] Фон листа: каждый готовый фон на экране и на печати (печатается ли без галочки «Фон» в окне печати); своя фотография на лист, прозрачность 40 %, «Вписать»; «Фон на оба листа»; скачанный HTML открывается с картинкой; «Звёздная ночь» с карточками — читается ли заголовок
- [ ] Рамки: все шесть стилей на светлой и тёмной теме — не закрывают ли текст, как выглядят на печати; цвет рамки ползунком.
- [ ] «Выравнивание»: ряд карточек «По верху» и «Распределить ↔» — ровный ряд с равными промежутками, на печати
      тоже; «Одна ширина» по образцу; тексты карточки (Shift+клик по ним) «По левому краю»
- [ ] «🔒 Закрепить» большой фон под карточками: рамка, начатая на фоне, выделяет карточки, а фон стоит;
      Delete его не удаляет (жёлтое предупреждение с «Открепить»); «Открепить всё на странице» снимает все замки страницы; текст закреплённой карточки печатается; после
      «Скачать HTML» и открытия файла объект всё ещё закреплён
- [ ] Несколько фигур подряд и «Дублировать» — новые объекты не ложатся друг на друга и видны на экране
- [ ] Загрузка картинок, фон карточки, Ctrl+V из буфера; крупное фото с телефона после загрузки выглядит чётко и на печати
- [ ] «Сжать картинки» в макете со старыми крупными фонами: сообщение «было … стало …», Ctrl+Z возвращает
- [ ] Скачать HTML → открыть скачанный файл → макет и редактирование на месте
- [ ] Chrome/Edge: Ctrl+S → окно выбора файла → выбрать открытый файл → «✓» и имя файла рядом с «Сохранено»;
      правка, Ctrl+S — без окна; закрыть вкладку и открыть файл снова — макет с правкой; после перезапуска браузера Ctrl+S спрашивает разрешение и пишет в тот же файл;
      Ctrl+Shift+S — другой файл; Firefox: Ctrl+S скачивает файл и объясняет почему
- [ ] Лента инструментов: на каждой вкладке иконки и подписи не налезают друг на друга; при переключении вкладок и выделении лист не прыгает; на узком окне вкладки уходят во вторую строку, а лента прокручивается вбок
- [ ] Приложение: https://valir-song.github.io/dnd-editor/ в Chrome → «Установить» → значок-кубик на рабочем столе,
      окно без адресной строки; без интернета (Wi-Fi выключен) открывается; бета `/beta/` ставится отдельным значком с β
      и не видит макетов основного приложения
- [ ] Файл `.dnd`: в приложении Ctrl+S → окно предлагает «Имя.dnd»; закрыть приложение, двойной щелчок по файлу в
      Проводнике → открывается приложение с этим макетом; Ctrl+O → «Недавние файлы» → «Открыть» (браузер спросит разрешение);
      открыть старый скачанный HTML → его макет, Ctrl+S — в него же; в Проводнике у `.dnd` значок-листок с кубиком
- [ ] Новый человек: приложение в окне инкогнито → пустой шаблон «ИМЯ ПЕРСОНАЖА» и жёлтая подсказка; вписать имя в шапку →
      название макета (Файл → Название) стало этим именем; «Файл → Новый лист…» → «Бард — Ричард Сэдсонг» → «Взять за основу»
      открывает копию; «Мои макеты» — оба листа; без интернета в приложении список готовых листов всё ещё есть
- [ ] Иконка кубика d20 на вкладке; «Создать ярлык…» в Chrome — ярлык с этой иконкой открывает редактор
- [ ] Экспорт и импорт JSON; импорт заведомо неверного файла ничего не ломает; JSON, скачанный в прежней
      версии (голый массив), открывается; в начале нового JSON видно `"formatVersion": 3`
- [ ] Скачанный HTML открывает свой макет, даже если в браузере сохранён другой; предупреждение позволяет открыть другой
- [ ] «Сбросить сохранение браузера» скачивает копию и открывает макет файла; Ctrl+Z возвращает
- [ ] Справочник заклинаний (на сайте, нужен интернет в первый раз): «Карточки → Заклинание…» — поиск, класс (запоминается), круг, «Моя СЛ», галочки → карточки как у Ричарда; 📖 на карточке показывает полный текст и после отключения интернета; на печати 📖 нет.
- [ ] Ресурсы: старый макет Ричарда открывается со строками вместо «□»; щелчок по квадратику закрашивает, ещё щелчок — снимает;
      над строкой выделенного окна «−»/«+», КО/ДО, колонка, удалить; «Короткий отдых»/«Длинный отдых»; на печати квадратики
      видны (закрашенные — цветом), кнопок над строками нет; на планшете квадратик нажимается пальцем
- [ ] Режим игры: «Игра» справа вверху → на панели только отдых и «К правке»; касание текста не ставит курсор и не выделяет,
      карточку не сдвинуть пальцем и мышью, лист прокручивается пальцем; квадратики и 📖 нажимаются; закрыть и открыть —
      снова режим игры; «К правке» — всё правится как раньше
- [ ] Масштаб: плашка справа внизу; −/+ и «По ширине»; Ctrl+колёсико мышью и щипок на тачпаде — точка под указателем остаётся
      на месте; на 50 % и 200 % перетаскивание, ручки, рамка-выделение, привязка и набор текста работают; после перезапуска
      масштаб тот же; печать и PDF при 200 % — обычный A4
- [ ] Листы: «+ Добавить лист», ↑/↓, «Копия», «Удалить» (вопрос, Ctrl+Z); «Карточки → На лист» для одной карточки и группы;
      макет Ричарда: поменять листы 1 и 2 местами — карточки выглядят как раньше; печать/PDF — все листы, без полосок над ними
- [ ] Печать / PDF на A4: нет панелей, ручек и рамок выделения
- [ ] На планшете: выделение и перетаскивание пальцем
