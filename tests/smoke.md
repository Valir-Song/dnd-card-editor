# Ручная проверка перед релизом

Автотесты (`npm test`, `npm run test:e2e`, `npm run test:e2e:firefox`) проверяют многое,
но не заменяют прогон с настоящим макетом. Перед проверкой скачай JSON текущего макета.

- [ ] `DND_Card_Editor_standalone.html` открывается без интернета в Firefox и Chrome
- [ ] Отображаются все объекты макета на обеих страницах
- [ ] Выделение кликом, Shift+кликом и рамкой по пустому листу; счётчик «Выбрано: N»
- [ ] Перемещение и изменение размера одного объекта и группы; отмена — одним шагом
- [ ] Клик по тексту карточки: рамка текста двигается за контур и меняет размер за ручки, карточка стоит на месте
- [ ] Shift+клик и Alt+рамка выделяют несколько текстов одной карточки; клик по пустому месту карточки возвращает к ней
- [ ] Значок уровня сдвигается отдельно
- [ ] **Firefox:** выделить карточку, зажать Shift и обвести рамкой другую — выделены обе (автотест в Firefox
      ведёт этот жест синтетическими событиями: Playwright не доставляет его настоящей мышью)
- [ ] Привязка: карточка прилипает к краю соседней, видна розовая линия; Alt и выключатель её отменяют; сетка 5 мм работает
- [ ] Редактирование и форматирование текста во всех типах полей
- [ ] Изменение → значок «✓ Сохранено»; закрыть и открыть файл снова (в Chrome и в Firefox) — изменение на месте
- [ ] Два скачанных файла с разными названиями: правки в одном не появляются в другом; «Файл → Мои макеты» показывает оба
- [ ] Закрытие вкладки сразу после правки большого макета: браузер спрашивает «покинуть страницу?» только пока идёт запись
- [ ] Ctrl+C / Ctrl+V объекта и группы: копия под оригиналом; Ctrl+X и Ctrl+V — на прежнее место;
      вставка в **другой** файл (в Chrome и **в Firefox** — там это проверяется только вручную); в тексте Ctrl+C/V копирует текст
- [ ] Группа (рамкой или Shift+клик): «Дублировать», слои, цвет фона действуют на все; Ctrl+Z — одним шагом
- [ ] Стрелки двигают карточку на 1 мм, Shift+стрелки — по сетке; удержание стрелки — плавный сдвиг, Ctrl+Z
      отменяет всю серию; в тексте стрелки двигают курсор; Esc после щелчка по тексту — стрелки двигают его рамку
- [ ] Сетка 5 мм видна бледными линиями и не мешает читать; на печати и в «Печать / PDF» её нет
- [ ] Перетащить карточку к ряду карточек: прилипает к тому же промежутку, видны розовые «10» и т.п.; не
      «залипает» навязчиво (порог маленький), Alt во время перетаскивания отключает; текст внутри карточки
      прилипает к её полю и к другим её текстам, но не к соседним карточкам
- [ ] «Выравнивание»: ряд карточек «По верху» и «Распределить ↔» — ровный ряд с равными промежутками, на печати
      тоже; «Одна ширина» по образцу; тексты карточки (Shift+клик по ним) «По левому краю»
- [ ] «🔒 Закрепить» большой фон под карточками: рамка, начатая на фоне, выделяет карточки, а фон стоит;
      Delete его не удаляет (жёлтое предупреждение с «Открепить»); текст закреплённой карточки печатается; после
      «Скачать HTML» и открытия файла объект всё ещё закреплён
- [ ] Несколько фигур подряд и «Дублировать» — новые объекты не ложатся друг на друга и видны на экране
- [ ] Загрузка картинок, фон карточки, Ctrl+V из буфера; крупное фото с телефона после загрузки выглядит чётко и на печати
- [ ] «Сжать картинки» в макете со старыми крупными фонами: сообщение «было … стало …», Ctrl+Z возвращает
- [ ] Скачать HTML → открыть скачанный файл → макет и редактирование на месте
- [ ] Экспорт и импорт JSON; импорт заведомо неверного файла ничего не ломает
- [ ] Скачанный HTML открывает свой макет, даже если в браузере сохранён другой; предупреждение позволяет открыть другой
- [ ] «Сбросить сохранение браузера» скачивает копию и открывает макет файла; Ctrl+Z возвращает
- [ ] Печать / PDF на A4: нет панелей, ручек и рамок выделения
- [ ] На планшете: выделение и перетаскивание пальцем
